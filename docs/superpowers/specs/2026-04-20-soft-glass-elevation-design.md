# 柔和玻璃悬浮视觉层级设计

## 目标

保留现有透明玻璃效果，为主搜索面板和内部卡片增加柔和、克制的悬浮厚重感，解决界面像单薄平面卡片的问题。

## 范围

- 主搜索面板的外层阴影。
- 设置页 `SettingsCard` 的内部卡片阴影和轻微高光边缘。
- JSON formatter 的独立窗口和工作区卡片的对应视觉层级。
- 阴影样式常量及相关单元测试。

不调整现有尺寸、布局、透明度、圆角半径、交互或内容层级。

## 设计方案

采用「柔和玻璃悬浮」方案：使用低不透明度的冷灰色多层阴影，而非纯黑的硬边投影。

### 主面板

- 启用原生窗口阴影，以确保无边框窗口能够相对桌面背景产生自然分离。
- 在 SwiftUI 根容器增加两层投影：
  - 近层：较小半径、较低位移，定义面板边缘；
  - 远层：较大半径、较低不透明度与向下位移，提供悬浮深度。
- 保持阴影柔和，避免深色壁纸中出现明显脏边。

### 内部卡片

- 为 `SettingsCard`、JSON formatter 工作区卡片等表面添加比主面板更短、更弱的阴影。
- 添加极轻微的亮色描边或顶部高光，形成“玻璃面板上的次级浮层”。
- 卡片阴影不得超过主面板阴影的视觉权重，避免争夺焦点。

### 样式边界

- 将阴影参数提取为可复用、可测试的样式常量，区分主面板和内部卡片两个层级。
- 主搜索面板与独立 JSON formatter 窗口均使用原生窗口阴影配置。

## 错误处理与兼容性

- 样式仅影响渲染，不新增运行时错误路径。
- 保持无边框窗口的现有窗口行为和尺寸计算；阴影不得改变命中测试或布局占用空间。

## 测试与验收

更新或新增单元测试，验证：

1. 主面板原生窗口阴影已启用；
2. JSON formatter 独立窗口原生阴影已启用；
3. 主面板和卡片使用不同层级的阴影配置；
4. 现有面板尺寸和内容状态规则不变。

手动视觉验收：在浅色与深色桌面背景下，主面板与内部卡片具有清晰但不厚重过度的层次；透明效果保持，阴影不呈现生硬黑边。
