# 启动器应用网格展开与 Finder 路径直达设计

## 目标

解决首次呼出后应用网格展开体验不足的问题，并让用户输入有效本地目录地址时可直接进入 Finder。

## 范围

### 应用网格原地扩张

- 保持当前 Ainto 面板的顶部、搜索框及水平方向位置不变。
- 点击应用网格的“展开”按钮后，面板只向下增高；点击“收起”时执行反向过渡。
- 折叠状态继续显示两行应用；展开状态显示完整应用网格。
- 新增图标按行显示，使用约 0.25 秒的淡入、轻微向上移动及小幅错峰动画。
- 展开或收起过程中保留当前选中项、键盘导航以及应用启动行为。
- 不引入全屏覆盖层或背景模糊层。

### Finder 目录路径结果

- 用户输入会先去除首尾空白。
- 若输入解析后是存在的本地目录，则在搜索结果最前方加入 Finder 直达结果。
- 支持绝对路径及以 `~` 开头的用户主目录路径。
- 该结果展示目录名称或完整路径、副标题“在访达中打开”及 Finder 图标。
- 用户点击或按回车时，通过 macOS Workspace 在 Finder 中打开该目录。
- 不存在路径、普通文件、空输入、无访问权限或不能解析的输入不生成该结果。
- Finder 结果优先于普通应用、指令和插件搜索结果；其余搜索流程不变。

## 实现边界

- 把路径标准化与目录判定提取成纯逻辑，避免将 `FileManager` 查询散落在视图代码中。
- 由 `SearchViewModel` 将 Finder 结果整合入当前搜索结果排序，不修改 Rust 的应用发现接口。
- 在 SwiftUI 网格容器和单项视图中实现动画；动画状态来自现有 `isApplicationGridExpanded`。

## 测试

- 路径逻辑覆盖：有效绝对目录、`~` 展开、空输入、不存在路径、普通文件、不可访问路径（若测试环境可稳定构造）。
- 验证 Finder 结果在查询结果中优先且执行动作正确。
- 验证应用网格展开策略和关键动画参数。
- 运行相关测试、完整 `swift test --package-path AintoApp`；若既有失败仍存在，单独记录。
- 按项目规则运行 `swift build --package-path AintoApp` 并启动 Debug 应用。

## 非目标

- 不制作全屏 Launchpad。
- 不新增 Finder 的文件选择、路径补全或文件打开功能。
- 不修改应用索引后台刷新机制之外的搜索架构。
