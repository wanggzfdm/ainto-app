# 柔和玻璃悬浮强度调校设计

## 目标

解决主面板与内部卡片的阴影均不明显、界面仍显单薄的问题，使悬浮层级在当前桌面背景下清晰可见，同时保持克制。

## 根因与范围

现有共享阴影参数的 opacity 偏低；冷灰色相较纯黑的视觉对比也更弱，导致主面板和卡片均难以形成层次。

本次只修改 `GlassElevationStyle` 中主面板和卡片的近/远阴影 opacity、半径和垂直偏移。保持冷灰颜色、圆角、material、布局、窗口行为、modifier 顺序及高光不变。

## 方案

采用「明显但克制」强度：

- 主面板：同步提升近层与远层阴影 opacity；远层增加半径和下移距离，形成一眼可见但不显脏的悬浮感。
- 内部卡片：适度提升近/远层阴影，仍保持所有关键参数低于主面板，避免抢占主面板焦点。
- 不向按钮、输入框、列表项增加任何阴影。

## 验收

1. 主面板和卡片阴影参数均高于调校前配置；
2. 卡片远层阴影的 opacity、半径及垂直偏移仍小于主面板；
3. 冷灰颜色、高光和现有布局测试保持；
4. 使用项目规定的 debug 构建启动流程后，在当前桌面背景下手动确认主面板和内部卡片均有清晰的悬浮层次。
