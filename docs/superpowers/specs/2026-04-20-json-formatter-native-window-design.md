# JSON 格式化工具原生可缩放窗口设计

## 背景

JSON 格式化工具可从主面板分离为独立窗口。该窗口当前使用 `.borderless` 样式，即使样式掩码包含 `.resizable`，在实际界面中也没有系统原生的边缘和角落缩放区域，用户无法调整窗口大小。

## 目标

将分离后的 JSON 格式化窗口改为标准 macOS 可缩放窗口：用户可以通过窗口四边和四角调整尺寸，并能使用系统标题栏的关闭和最小化功能。

## 非目标

- 不保留无边框窗口外观。
- 不实现自定义边缘命中测试或手动缩放逻辑。
- 不改变 JSON 格式化、压缩、复制、筛选、编辑或内嵌主面板模式。
- 不调整窗口初始尺寸或最小尺寸。

## 设计

### 窗口样式

`JSONFormatterWindowStyle.styleMask` 始终返回以下 AppKit 样式掩码：

- `.titled`
- `.closable`
- `.miniaturizable`
- `.resizable`

`SearchPanel.openJSONFormatterWindow()` 保持使用该样式创建 `NSWindow`。窗口仍使用初始尺寸 `900 × 760` 与最小尺寸 `800 × 600`。

### 行为

AppKit 将负责标题栏、窗口拖动、缩放命中区域和系统窗口控制。现有 `DetachedJSONFormatterView` 不再承担窗口缩放职责，继续只提供 JSON 格式化内容及“嵌回主面板”和“关闭”操作。

### 测试

为窗口样式添加单元测试，验证：

1. 样式包含 `.titled`、`.closable`、`.miniaturizable`、`.resizable`。
2. 样式不包含 `.borderless`。

该测试防止后续视觉调整重新引入无边框且不可缩放的窗口配置。

## 验收标准

1. 打开 JSON 格式化工具的独立窗口后，可拖动任意窗口边缘和四个角调整尺寸。
2. 窗口显示 macOS 原生标题栏及关闭、最小化按钮。
3. 窗口不能缩小到 `800 × 600` 以下。
4. JSON 工具现有功能保持可用。
5. 新增窗口样式单元测试通过，且项目测试与 debug 构建通过。

## 风险与处理

原生标题栏会改变独立窗口的视觉外观；这是已选择的方案，换取系统级一致性和可靠的缩放行为。内容视图仍维持现有圆角和材质效果，功能逻辑无需修改。
